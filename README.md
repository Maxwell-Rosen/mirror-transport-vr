# Mirror Transport VR

A virtual museum for exploring magnetic mirror equilibrium and plasma transport through simulation data from Maxwell Rosen’s PhD thesis. The project is in the planning stage for standalone Meta Quest 3 and desktop, using Godot 4 and OpenXR.

The first planned exhibit pairs a five-metre magnetic mirror with a movable probe. Visitors will be able to follow a field line and inspect the ion velocity distribution at the same position. [Exhibit and development plan](PLAN.md)
